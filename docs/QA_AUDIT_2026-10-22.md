## 已确认问题与修改记录

### QA-01：教程目录请求了过期的工具清单缓存版本

**严重程度：中。状态：已修复。**

巡检时，`tutorials/index.html` 抓取工具目录所用的地址是 `../app.js?v=20261004-6`，而首页当前引用 `app.js?v=20261021-1`。该脚本会从工具数组构建教程目录。版本查询参数长期不变时，浏览器或缓存层可能继续复用旧资源，导致教程目录显示的工具列表落后于首页。此处已确认的是版本号不一致，是否有用户实际遇到旧缓存未能在当前环境中实测。

**修改：** 将教程目录中的 `app.js` 查询参数统一到 `20261021-1`。

### QA-02：教程和 SEO 详情页使用了旧的共享资源缓存版本

**严重程度：中。状态：已修复并提交。**

教程目录使用的共享 `style.css` 与 `i18n.js` 版本号落后于首页；SEO 静态详情页生成器的模板也引用旧版共享样式与多语言脚本。这样存在页面间复用到不同旧缓存版本的风险。

**修改：**
- `tutorials/index.html` 中 `style.css`、`i18n.js` 更新为 `20261021-1`。
- `scripts/build-seo-pages.mjs` 中生成的详情页共享 `style.css`、`i18n.js` 引用更新为 `20261021-1`。

**提交：**
- `e1c0efb300b32af62bbf5a2213eb18fa01b08e91`：教程目录缓存版本更新。
- `bc3b76acc73a6a858897749b2b821782a266a05c`：SEO 详情页模板缓存版本更新。

**静态复核办法：** 重新读取两份文件，确认教程目录不再包含 `app.js?v=20261004-6`、`style.css?v=20261016-1` 和 `i18n.js?v=20261007-1` 这三个旧引用；SEO 生成器中的共享样式和多语言脚本也使用 `20261021-1`。

### QA-03：仓库 Homepage 元数据和正式站点主域名不一致

**严重程度：中。状态：待仓库设置修复。**

仓库 API 返回的 Homepage 为 `https://2392480227h-rgb.github.io/ai-tools/`；但首页 canonical、Open Graph URL、`robots.txt` 的 Sitemap 和 SEO 页面生成器使用的是 `https://starterhub-dev.github.io/ai-tools/`。

这不一定会导致网站本身打不开，但会令 GitHub 仓库中的 Website 入口指向另一地址，造成访问入口混淆。

**跟进：** [Issue #35：统一 GitHub 仓库主页与网站 canonical 域名](https://github.com/starterhub-dev/ai-tools/issues/35)。

**建议修改路径：** GitHub 仓库 Settings → General → Website，将 Homepage 更新为 `https://starterhub-dev.github.io/ai-tools/`，之后检查仓库页上的链接。

### QA-04：仓库中跟踪的 sitemap 时间戳较旧

**严重程度：低。状态：已记录，当前不作为已确认的线上故障。**

被 Git 跟踪的 `sitemap.xml` 中，抽查的 `lastmod` 值仍为 `2026-10-04`。不过 `scripts/build-seo-pages.mjs` 会在 Pages 部署流程中重新生成 Sitemap，并使用构建日期。因此仓库内文件较旧并不等于已部署文件也较旧；当前环境无法直接读取线上 Sitemap 来作最终确认。
