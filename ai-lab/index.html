03 / HOW IT WORKS

为什么这里可以免费用？

01

算力在你自己的设备上

浏览器借助 WebGPU 调用设备 GPU 进行推理，不是把每条消息发到我们的模型服务器。

02

不需要账号与 API Key

页面没有接入付费推理 API。模型文件从公开模型托管平台获取，首次下载需要网络流量。

03

开源项目，模型许可透明

本页使用 WebLLM 作为浏览器推理引擎。每个模型卡都链接到对应模型说明，模型权重遵循各自许可证。
